# Car Detection Using YOLO26 and Roboflow

## Project Overview
This project demonstrates car detection using a YOLO26 object detection model. The dataset was obtained from Kaggle, and image annotation and model training were performed using Roboflow.

## Objectives
- Detect cars in images.
- Prepare and annotate image data.
- Train an object detection model using Roboflow.
- Review model predictions and evaluation results.

## Technologies Used
- YOLO26
- Roboflow
- Computer Vision
- Object Detection

## Dataset
- Source: Kaggle
- Annotation and training platform: Roboflow
- Target object: Car
- Roboflow project:https://app.roboflow.com/anjalis-workspace-79e7f/car-object-detection-bkwok/models?openModelEval=true

## Workflow
1. Downloaded the car dataset from Kaggle.
2. Uploaded images to Roboflow.
3. Annotated cars using bounding boxes.
4. Created a dataset version.
5. Trained the selected YOLO26 model.
6. Reviewed the detection predictions.

## Results
Screenshots of the actual detection results will be added to the `results` folder.

## Limitations
Detection performance may vary depending on image quality, lighting, object size, and the dataset used.
